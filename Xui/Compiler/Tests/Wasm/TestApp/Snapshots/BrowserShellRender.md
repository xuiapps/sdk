# TestApp mobile shell: first frame

[Open standalone page](BrowserShell.html). Real Window/RootView activation and TestAppDesignRoot supply the mobile theme. The browser catalogue contains Canvas Drawing; the optional diagnostics overlay is omitted. Layout and drawing execute in WASM; Canvas text metrics and drawing cross explicit host imports. This first-frame test does not dispatch input.

Sources: [Program.cs](Fixtures/TestApp/Browser/Program.cs), [CanvasContext.cs](Fixtures/TestApp/Browser/CanvasContext.cs), [Platform.cs](Fixtures/TestApp/Browser/Platform.cs), [BrowserMenu.cs](Fixtures/TestApp/Mobile/BrowserMenu.cs).

## Source

```csharp
using System;
using Xui.Apps.TestApp;
using Xui.Core.Math2D;
using TestAppCanvas;

public static class Program
{
    public static int Main()
    {
        try
        {
            var metrics = new MobilePerformanceMetrics();
            var context = new CanvasContext();
            var window = new Xui.Core.Abstract.Window(new BrowserPlatform(context))
            {
                DisplayArea = (0, 0, 393, 759), SafeArea = (0, 0, 393, 759),
                Content = BrowserMenu.CreateRoot(metrics)
            };
            var shell = window.RootView;
            var desired = shell.Measure((393, 759), context);
            shell.Arrange(new Rect(0, 0, 393, 759), context, desired);
            shell.Render(context);
            return 0;
        }
        catch (Exception error)
        {
            NativeCanvas.Command("Error", text: error.Message);
            return 1;
        }
    }
}
```
